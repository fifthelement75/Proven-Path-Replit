# Career Passport - Interview Skill Assessment Templates

Add the interview assessment system to Career Passport:

---

## Part 1: Interview Process Integration

### Interview Assessment Flow

1. **During Interview:**
   - Interviewer opens "Interview Assessment" section
   - Selects candidate name, role they interviewing for
   - Uses role-specific Skill Assessment with Scoring Sheet
   - Scores each skill (1-5 scale based on level benchmarks)
   - Adds written feedback for each skill

2. **After Interview:**
   - Submits assessment → stored in system as "Interview Assessment"
   - Multiple interviewers can add assessments for same candidate

3. **If Hired:**
   - Manager goes to add new employee
   - Can search for candidate by name
   - System shows "Import Interview Assessment" option
   - Click to import scores into employee profile
   - ATS integration (future): Greenhouse/Lever API auto-imports

4. **Benchmarking:**
   - 6-month performance review scores can be compared to interview scores
   - Shows growth trajectory: Did they improve? Stagnate?

## Part 2: Skill Assessment Templates by Role

Each role has templates for levels: **Junior (or Associate), Intermediate (or Mid), Senior, Principal (or Lead/Manager)**

### Scoring Scale (Same for All)

| Score | Level | Description |
|-------|-------|-------------|
| 1 | Below Expectations | Does not demonstrate this skill |
| 2 | Approaching Expectations | Demonstrates basic understanding |
| 3 | Meets Expectations | Solid competence for level |
| 4 | Exceeds Expectations | Strong performance above level |
| 5 | Outstanding | Exceptional, ready for next level |

## Part 3: Database Integration

Add these tables:

```
InterviewAssessment:
- id
- candidateName
- candidateEmail
- role (Designer/PM/Engineer/QA/PMM)
- level (Junior/Intermediate/Senior/Principal)
- interviewerId
- interviewDate
- status (pending/hired/not-hired)
- scores (JSON: skillName: score)
- feedback (JSON: skillName: comment)
- overallRecommendation
- createdAt

CandidateProfile:
- id
- name
- email
- phone
- roleApplyingFor
- resumeUrl
- source (LinkedIn/Referral/Job Board)
- status (interviewing/offered/hired/rejected)
- createdAt
```

## Part 4: UI Pages to Build

1. **Interview Assessment Page**
   - Select candidate or create new

   - Score each skill 1-5
   - Add comments per skill
   - Submit assessment

2. **Candidate Dashboard**

   - Filter by status/role/date

3. **Employee Import Flow**
   - Search for candidate name
   - "Import Interview Scores" button
   - Maps interview assessment to employee profile
   - Shows comparison when 6-month review complete
