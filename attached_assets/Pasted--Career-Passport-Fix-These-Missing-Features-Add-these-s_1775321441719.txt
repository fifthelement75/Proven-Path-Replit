# Career Passport - Fix These Missing Features

Add these specific features to the existing Career Passport app:

---

## 1. User Profile Access (Critical!)

Currently logged-in users can't access their own profile. Fix this:

**After login:**
- Redirect to `/dashboard` which shows company overview
- Add a "My Profile" button in navbar (or dropdown with user name)
- Clicking "My Profile" goes to `/profile/me` or `/employees/me`
- This page shows:
  - Current user's profile (name, role, department, level)
  - Their own reviews (self-assessment tab)
  - Their development plan
  - Their feedback history
  - "Share My Profile" button
- User can edit their own profile info (except role/level)
- User can view but not edit company-assigned fields

---

## 2. Role-Based Permissions (Critical!)

Add proper access control with middleware:

**Data Model:**
```
Users table add: role (admin | manager | employee)
Employees table: managerId (links to another employee)
```

**Permissions:**
| Role | Access |
|------|--------|
| **Admin** | Full company access, can add/remove employees, view all |
| **Manager** | Only can see employees where employee.managerId = their user id, can add reviews for direct reports |
| **Employee** | Only can see own profile, own reviews, own dev plan |

**Implement:**
- Add auth middleware that checks user.role
- Protect routes: /api/employees (only admin sees all)
- Managers get /api/employees?managerId={id} for their team
- Employees get /api/employees/me
